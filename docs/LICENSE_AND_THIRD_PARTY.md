## Network deployments

A modified AGPLv3-covered Tihulu web service must provide an appropriate source-code offer to users interacting with it over a network, pursuant to **AGPLv3 section 13**. The future **About → Source Code / License** page should point to the exact corresponding source revision and identify any modifications. Posting a repository URL without including the corresponding deployed source is not automatically sufficient for independently modified deployments.

## Third-party packages and content

The Tihulu license **does not relicense** upstream components or archives. Separately review and comply with the specific terms for Kiwix, Kolibri, Wikipedia ZIM/dumps, OpenStreetMap data, Project NOMAD, embedded fonts, imagery, pretrained AI models, SDR/DVB firmware, and each bundled radio/TV/news source. Some content may prohibit redistribution even when client software is open source.

Keep copyright notices, source code obligations, credits, and license files with redistributed components. Do not assume all externally linked news articles, political posts, teletext broadcasts or TV recordings may be mirrored or relicensed.

## Contribution conventions

- Add `SPDX-License-Identifier: AGPL-3.0-only` to new code modules where practical.
- Preserve upstream attribution and avoid copying third-party code without license compatibility review.
- GitHub collaboration in English is preferred. Localized Turkish and German UI or docs remain welcome.
- The product is **not released or installed** merely because a LICENSE file exists.
